# 桌面宠物（Live2D）

Windows 桌面上的 Live2D 桌宠。默认形象是 Live2D 官方样例角色 Haru：
待机时呼吸、眨眼、跟着光标转头，被摸头会笑，被连续猛点会生气。

> **许可提示：** 官方样例模型限非商业用途；Cubism Core 为 Live2D 专有许可代码。
> 分发前请先读 [NOTICE](./NOTICE)。

## 功能

- 透明无边框、置顶的桌宠窗口；Live2D 待机动画、呼吸、眨眼与物理效果
- 视线跟随光标（**光标不在桌宠身上时它也看着你**）
- **单击**摸头（换表情与动作），**双击**打开插件面板
- 情绪系统：心情随互动起伏，久不理它会犯困，被连续猛点会生气
- 按住拖拽移动，位置自动记忆；拖到屏幕边缘自动贴齐，还能滑出屏幕只留一条边
- **按住 Ctrl + 滚轮**调整桌宠大小（也可以在设置窗口里拖滑块）
- **插件面板**：模糊搜索插件，回车打开插件界面
  （待办、提醒、番茄钟、天气、剪贴板、系统状态、录屏）
- **同一个搜索框还能搜本机程序**（开始菜单、PATH、程序目录），回车就启动
- **搜索范围和 Win+S 一样宽**：程序、本机文件（走系统搜索索引，连文档里的字都搜得到）、系统设置页
- **每条结果都带自己的图标**，点右键还能「打开」「打开所在目录」
- **同一个搜索框还能跟桌宠说话**，回复在旁边的气泡里逐字冒出来
- 语音播报（MiniMax TTS）+ 口型同步；音色与 API Key 可配置
- **点桌宠时它会说话**：用你设定的音色念一句台词，台词可以自己写
- 开机自启；全局快捷键（呼出/隐藏桌宠、唤醒搜索框）
- **鼠标穿透**：点不到桌宠，桌面照常操作（桌宠仍跟着光标转头）
- 多显示器与 DPI 适配；运行时切换形象；导入自己的 Live2D 模型
- 系统托盘菜单（显示隐藏 / 取回桌宠 / 设置 / 退出）

## 环境要求

- Windows 11
- Node.js ≥ 20

## 快速开始

```bash
npm install     # 安装依赖（含 Electron 自动下载）
npm run setup   # 下载 Live2D 官方样例模型 + 生成托盘图标
npm start       # 启动桌宠
```

`npm run setup` 需要联网（从 GitHub 拉取官方样例资源）。执行一次后资源会缓存在
`assets/live2d/models/` 下，之后可离线重复运行。

> **模型二进制不在版本库里。** 仓库只提交手写的 `pet.json` 清单，
> 各样例的 `.moc3`、贴图、动作等二进制由 `npm run setup` 下载。
> 全新克隆的仓库必须先跑一次 `npm run setup`，否则桌宠窗口里没有任何模型。

## 使用说明

### 插件面板（双击桌宠）

**双击一下桌宠**，桌宠旁边会弹出一个搜索框：

```
┌─ 插件面板 ─────────────────┐
│ ✨  待办▌                  │
├────────────────────────────┤
│ ✓  待办       查看与添加待办 │
│ ⏰  提醒       到点提醒你做事 │
│ 🍅 番茄钟      专注与休息计时 │
└────────────────────────────┘
```

打几个字就能**模糊搜索**——中文名、英文、拼音都认（「待办」「todo」「daiban」都行）。
点一下结果或按 **Enter** 就打开那个插件的界面（同一个窗口换内容，**Esc** 回到搜索）。

这个框**不止是搜索**：它也能直接跟桌宠说话。框里的提示写着
「搜索插件、程序、文件、设置，或跟桌宠说点什么…」——回车时如果匹配不到插件（或按 **Ctrl+Enter**），
这句话就发给桌宠，回复出现在桌宠旁边的气泡里。

同一个框里能搜的东西，**和 Win+S 一样宽**：

| 搜什么 | 从哪来 | 回车 / 点击会发生什么 |
| --- | --- | --- |
| 插件与内置功能 | 插件目录 | 打开插件界面 |
| 本机程序 | 开始菜单、PATH、程序目录 | 启动它（输入「note」能搜到记事本） |
| 本机文件 | **Windows 搜索索引**（就是 Win+S 用的那个）：文件名与**文件内容**都搜 | 用系统默认程序打开 |
| 系统设置 | 设置页与控制面板清单 | 打开对应的设置页 |
| 网页 | — | 用浏览器搜这句话 |

每条结果都带**自己的图标**：程序是开始菜单里那个图标，文件是它自己的类型图标。
结果上**点右键**还有菜单：打开、**打开所在目录**（在资源管理器里定位到它）。

索引扫的是开始菜单、PATH 与程序目录（`C:\Program Files` 等），应用启动时后台扫好，按需刷新。
文件走的是系统自己的搜索索引，所以搜得到的地方和 Win+S 一样多；
索引用不了时（服务没开）会自动改扫桌面、文档、下载这些常用文件夹。

| 插件 | 说明 |
| --- | --- |
| 待办 | 加一条、点一下完成、清除已完成 |
| 提醒 | 「30分钟后喝水」「2小时后」「14:30」「明天 9:00」都认 |
| 番茄钟 | 25 分钟专注 / 5 分钟休息，可暂停继续重置 |
| 天气 | 填一个城市名后开启，定时播报（open-meteo，免密钥） |
| 剪贴板 | 剪贴板历史：双击就贴出去，能固定、能搜索（历史存在本机） |
| 系统状态 | CPU、内存、温度、电源；还能变成桌面小部件 |
| 录屏 | 全屏 / 选区 / 窗口录制，输出视频或 GIF |
| 音乐播放器 | 放本机音乐；能变成桌面小部件，还能开桌面歌词 |

另有两项**内置功能**，它们不是插件（关不掉、也不在插件目录里），
但同样能在面板里搜到、打开：**设置**（开设置窗口）与**聊天记录**
（和桌宠说过的话，可一键清空）。

插件界面里直接改数据（加待办、勾完成、开关剪贴板助手……），改完立刻反映在界面上。
桌宠自己的**说话气泡**只负责显示它说了什么，点击穿透、不挡桌面的操作。

### 剪贴板（CopyQ 那一套）

面板里打开「剪贴板」，它就是一个**剪贴板管理器**：

| 动作 | 怎么做 |
| --- | --- |
| 记历史 | 复制什么就记什么（顶栏的「记录」可以关）。历史**存在本机**（`userData/clipboard-history.json`），退出后还在 |
| 贴出去 | **双击**一条：内容写回剪贴板，并给**刚才在用的那个窗口**发 Ctrl+V |
| 固定 | 点条目左边的**图钉**：固定的排在最前面，而且**不会被淘汰** |
| 找一条 | 顶栏的搜索框（本地筛，不卡） |
| 删 / 清空 | 条目右边的 ✕ / 顶栏的「清空」 |
| 快捷键 | 点右下角的**齿轮**：改「打开历史」「粘贴最近一条」两个键，**在剪贴板自己的页面里**改 |

> 贴出去要往别的进程发按键，Electron 没有这个接口——
> 这一步由插件自带的 `paste.ps1` 干（找出刚才在用的那个窗口 → 叫到前台 → 补发 Ctrl+V）。
> 找不到窗口时会告诉你，不会乱贴到别处。

> **历史是明文存着的。** 剪贴板里可能有验证码、密码、私人聊天——
> 那些都会原样写进 `userData/clipboard-history.json`。
> 不想要就把顶栏的「记录」关掉（或删掉那个文件），
> 它立刻就不再记了。桌宠**助手**那边（复制时在气泡里提示一句）依旧只留在内存里。

### 音乐播放器

面板里打开「音乐播放器」，它就放你本机上的音乐。**完全离线**，不连任何服务器。

| 动作 | 怎么做 |
| --- | --- |
| 选音乐库 | 右上角的**「音乐库」**按钮，选一个文件夹。里面的音频文件（mp3 / flac / m4a / wav…）会连子目录一起收进曲库 |
| 放歌 | 点曲库里的一首。歌名与歌手从**文件名**里认（「歌手 - 歌名.mp3」） |
| 桌面小部件 | 面板上的 **▣**：一块常驻桌面的迷你播放器，带播放、上一首、下一首与进度条 |
| 桌面歌词 | 界面上的**「词」**按钮：桌面上浮起一块小窗，当前那句大、亮，其余小、淡。它一直浮着，能拖到别处去 |
| 找歌 | 直接跟桌宠说「放一首《稻香》」「下一首」也行 |

> **歌词从哪来**：每首歌**同目录**下的同名 `.lrc` 文件。
> 两种摆法都认：「歌手 - 歌名.lrc」与「歌名.lrc」。中文歌词多半是 GBK 编码的，插件会自己认。
> 没有歌词文件时，歌词窗里只有歌名。

面板上永远有 **↗**（在新窗口打开）；插件自带桌面小部件时还会多一个 **▣**。

- **独立窗口**：自己的窗口，能调整大小、能拖到别处；标题栏上有 **📌** 置顶开关；
- **桌面小部件**：无边框、透明、常驻桌面（像系统监控那样挂在那儿），整块可以拖。

两者是同一个窗口的两种样子，可以来回切。

### 和桌宠聊天

面板的输入框**也能直接对桌宠说话**：

- 输入的话**匹配不到任何插件**（比如「在吗」）→ 回车＝发给桌宠；
- 匹配到插件 → 回车＝打开那个插件；
- **Ctrl+Enter 永远发给桌宠**（哪怕这句话也匹配得到插件）。

桌宠的回复显示在它旁边的**气泡**里，**一个字一个字地冒出来**。

在设置窗口的「对话」一节里可以改：

| 项 | 说明 |
| --- | --- |
| 接口地址 / 模型 | 走 OpenAI 兼容协议，填别的服务商也能用（模型名以那家的控制台为准） |
| 温度 / 回复长度 | 越大越啰嗦 |
| 对话 Key | 留空＝沿用上面那个 MiniMax Key |
| 人设 | 名字、性格、背景——决定它怎么说话 |
| 主动搭话 | 默认关。开了之后它会按间隔主动开口（深夜不打扰） |

桌宠会记住你说的事（短期记最近几轮，长期记「事实」），
回复里的情绪也会反映到它的表情上。记住了什么，可以在设置窗口的**「记忆」**一节里逐条查看、一键清空。

> 聊天要花钱、要联网、还依赖模型名，默认**关闭**。没配 Key 会每次都失败；
> 模型名填错会返回「该模型未开通」。聊天记录是**内置功能**（不是插件）：
> 在面板里搜「聊天记录」就能打开。

### 语音播报

语音走 **MiniMax TTS**。在设置窗口里填 API Key、选音色、调语速即可；
不填就只显示文字气泡，不出声。

- API Key 存在 `userData/credentials.json`，**不进渲染层**，界面上只显示掩码（`****abcd`）。
- 音色是自由输入 + 建议列表：建议表里的 id 都验过能用，但新音色随时会加，
  所以也可以直接填任意合法的 `voice_id`。
- 「语音」分区里还有一个**总音量**滑块——提示音与桌宠说话**一起**受它管。

#### 点桌宠时它说什么

「语音 → 点桌宠时」这一节管的是**点一下桌宠**的反应：

| 开关 | 效果 |
| --- | --- |
| 点桌宠时说话 | 开：点一下，桌宠念一句台词；关：不念台词（模型自带的声音照旧） |
| 也用 Live2D 模型自带的声音 | 开：模型自带的 wav 和生成的台词**一起随机抽**；关：只用生成的台词 |
| 台词（每行一句） | 自己写台词，最多 20 句、每句 60 字 |

- **台词的语音是事先合成好的**：应用启动后、改了音色或台词后，都会在后台把每句台词
  合成一遍存到本地（`userData/tts-cache/tap/`）。点击时读的是本地缓存——**不调接口**，也没有等待。
- 换音色不用手动清缓存：缓存按「台词+音色+语速+音量+音高」的内容哈希存，换了就自动重新生成。
- **点一下只出一声**：3 秒内连点不会再念第二句（语音会叠在一起）。
- **模型自带的声音是兜底**：没配 Key、语音没开或没有台词时，桌宠的行为和这个功能
  存在之前一模一样——模型自己出声。
- 台词的气泡摆在**脚下**——点桌宠时插件面板在头顶，两者不重叠。

> 语音播报依赖外部接口：需要联网与有效的 API Key；没配或合成失败时**静默降级**成
> 纯文字气泡（终端里留一行日志）。

### 设置窗口

托盘菜单或桌宠右键菜单里的「设置…」打开（面板里搜「设置」也行）。
左边是分区目录，右边一次只显示一节：

```text
┌──────────────┬────────────────────────────────────────┐
│ 外观   Haru  │  外观                                  │
│ 助理    3/3  │  桌宠长什么样，在桌面上占多大。           │
│ 语音    已关  │  ──────────────────────────────────    │
│ 对话    缺 Key│  形象   [Haru                   ▾]      │
│ 记忆    3 条 │  缩放   ───────●──────      1.00x      │
│ 插件    6/6  │                                        │
├──────────────┴────────────────────────────────────────┤
│ 设置即时生效并自动保存                    已保存 ✓    │
└───────────────────────────────────────────────────────┘
```

目录右边那一列是**状态摘要**：不进每一节也看得出现在是什么状态
（助理开了几项、语音有没有 Key、记住几条事实、几个插件开着）。
设置**即时生效并自动保存**。

#### 哪些设置在设置窗口，哪些在插件里

设置窗口管的是**应用级别**的东西：桌宠长什么样、助理什么时候开口、语音与对话怎么配、
开机自启与快捷键，以及**装了哪些插件、开着哪些**。

**某个插件自己的配置不在这里**——它在那个插件的页面里：

| 插件 | 它的设置在哪 |
| --- | --- |
| 剪贴板 | 面板里打开「剪贴板」→ 顶栏开关「记录」、点右下角**齿轮**改快捷键与保留条数 |
| 天气 | 面板里打开「天气」→ 填城市、开关定时播报 |
| 系统状态 | 面板里打开「系统状态」→ 开关「过热时提醒我」 |
| 录屏 | 面板里打开「录屏」→ 模式/声音/格式；点右上角的**齿轮**打开设置抽屉，改存放位置、快捷键、录制质量 |
| 音乐播放器 | 面板里打开「音乐播放器」→ 右上角**「音乐库」**选文件夹；界面上调音量、换播放模式、开桌面歌词 |

这样安排有个实在的好处：设置窗口**不会**把插件页面改过的设置覆盖回去（它连这些字段都不碰）。

待办、提醒、番茄钟的状态存在 `userData/assistant.json`，退出后仍然保留。

### 开机自启 / 快捷键 / 鼠标穿透

设置窗口的「**系统**」分区管的是桌宠与 Windows 的关系：

| 项 | 说明 |
| --- | --- |
| 开机自启 | 登录 Windows 后自动拉起桌宠。默认关 |
| 全局快捷键 | 默认 `Control+Shift+D`，点「重新录制」按新的组合。**至少要带一个修饰键**（Ctrl / Alt / Shift）——裸键会劫持你所有的字母键 |
| 输入框快捷键 | **默认不设**。设好之后按这个组合会唤出插件面板，焦点直接落在搜索框里，可以立刻打字。点「清除」可以把它撤掉 |
| 鼠标穿透 | 开了点不到桌宠，桌面照常操作；桌宠仍跟着光标转头。托盘菜单里也有这个勾选项 |
| 边缘吸附 | 拖到屏幕边缘附近时自动贴齐（默认开） |
| 贴边隐藏 | 贴齐后滑出屏幕，只留一条边；**拖那条边可以把它拽回来**（默认关） |

**快捷键被别的程序占用时**（Windows 上这是静默失败，接口不报错），
设置窗口会写明「该组合已被其他程序占用」。换组合时是先注册新的、成功了再注销旧的，
所以**换组合失败时原来那个组合仍然有效**。

两个快捷键**不能设成同一个组合**：设置窗口会说「这个组合已经被『呼出 / 隐藏桌宠』用了」，
而不是含糊地说「被其他程序占用」——占着它的是这个应用自己。

桌宠停靠在屏幕边缘外时，托盘菜单与右键菜单里会多出一项「**取回桌宠**」；
不开穿透的话，也可以直接拖那条边把它拽回来。

### 形象

程序自带 3 个 Live2D 官方样例角色，设置窗口的「外观 → 形象」里可以直接切换：

| 形象 | 表情 | 备注 |
| --- | --- | --- |
| Haru | 8 个（`F01`…`F08`） | 默认形象 |
| Hiyori | 无 | 只有动作，没有表情文件 |
| Mao | 8 个（`exp_01`…`exp_08`） | 表情语义见下 |

- **模型文件不随程序分发**：`npm run setup` 从 Live2D 官方仓库把它们下载到
  `assets/live2d/models/`（每个约 9MB）。仓库里只保留每个模型手写的清单 `pet.json`。
- **预制的形象也能移除**：在设置窗口里选中它，点旁边的 **「删除」** 即可从形象列表里去掉。
  移除只是记一笔账，程序目录里的模型文件不会被删——想让它回来，删掉那个文件即可。
- **至少要保留一个形象**：删到只剩最后一个时不允许再删。

桌宠放大到屏幕放不下为止：窗口尺寸跟着缩放走，但不会超过所在显示器的可见工作区。
所以在小屏幕上，滑块拖到底也未必达到 2.0 倍的实际尺寸。

#### 导入自己的形象

设置 → **外观** → 形象那一行右侧的 **「导入模型…」**：

1. 选一个 Live2D 模型**文件夹**（不是单个文件——模型是一整套文件：
   设置清单、`.moc3`/`.moc`、纹理、动作、表情）。
2. 应用把它复制到用户数据目录 `<userData>/live2d/models/<id>/`，
   校验完整性，注册进形象列表，并**立即切换**到这个新形象。
3. 导入的形象会标注「（导入）」，可以随时用旁边的 **「删除」** 按钮删掉。

导入的形象**重启后依然在**（存在用户数据目录里，不在程序安装目录），
因此装到 `Program Files` 下也没有问题。

几点说明：

- **两种 Cubism 格式都支持**：
  - Cubism 4：`.model3.json` + `.moc3`
  - Cubism 2：老格式，`.model.json` 之类 + `.moc`

  格式是按设置文件的**内容**判别的，不是文件名：老模型的设置文件叫什么都行。
- **模型根目录 = 设置文件所在的目录。** 纹理与动作的相对路径是按它解析的，
  所以可以直接选装着模型文件夹的父目录——应用会自动认出里面那层。
- 导入的模型**默认不写表情语义映射**，会走降级路径：只播动作、不套表情。
  但**你自带的 `pet.json` 会被原样保留**——模型文件夹里已经放了一份的话，
  应用不会覆盖它，里面写好的表情/动作语义映射照常生效。
- 复制有上限（200 MB / 2000 个文件）：文件夹选择器允许误选整个家目录，
  没有上限的话一次手滑就是几十上百 GB。
- Cubism 2 老模型**没有口型同步**：语音播报时嘴不会跟着动（不影响其它功能）。

想手动把模型放进项目里、或者要写 `pet.json` 清单，见
[《添加自己的形象》](./docs/开发说明/添加自己的形象.md)。

### 录屏

面板里搜「**录屏**」：

- **三种录法**：全屏、选取（像截图那样在屏幕上拉一个框）、窗口；
- **录哪一块**：选了之后，面板里会列出能录的显示器和窗口，点一个就是它；
- **声音**：麦克风与扬声器可以分开开，也可以一起开（自动混音）；
- **两种格式**：视频（H.264 + AAC）或 GIF（**GIF 存不了声音**）；
- **存放位置**：默认是系统的「视频」文件夹，可以在插件里改；
- **快捷键**：默认 `Control+Shift+R`（停止是 `Control+Shift+S`），可以改。
  打开过一次录屏之后就一直生效，不用开着窗口；
- 录制时桌面上会出现一个置顶的小控制条，显示录了多久，点「停止」就停；
- 录着录着被录的那个窗口被关掉了？录制会自己停下来，已经录的照样存下来。

## 开发

```bash
npm run test:unit   # 纯函数单测（node:test），秒级
npm run test:e2e    # 端到端测试（Playwright + Electron），会真的开窗口
npm test            # 两个都跑
```

E2E 用临时 userData（`DESK_PET_USER_DATA`、`DESK_PET_E2E=1`），不会碰你真实的配置。

```text
src/main/       主进程：窗口、托盘、菜单、设置持久化、多显示器
src/preload/    contextBridge 白名单 API
src/renderer/   渲染层：Live2D 模型与交互、插件面板、设置窗口
src/shared/     主进程与渲染层共用的契约
plugins/        内置插件，一个插件一个子目录
assets/live2d/  模型资源与 pet.json 清单
vendor/live2d/  官方 Cubism Core（专有许可代码）
docs/开发说明/  插件系统与形象的详细文档
```

写插件看[《插件开发指南》](./docs/开发说明/插件开发指南.md)，
改宿主看[《插件系统架构》](./docs/开发说明/插件系统架构.md)，
写模型清单看[《添加自己的形象》](./docs/开发说明/添加自己的形象.md)。
