# 外部（非内置）插件

这里放**不随应用分发**的插件：源码在仓库里（能改、能测、有版本记录），
但应用本身不带它们——要用它们，自己装一份到用户插件目录。

## batch-rename（批量重命名）

多选或**拖进**文件，按规则批量改名：重新命名为（模板，`度假_{n}` 式）、查找/替换（含正则）、前后缀、
大小写转换、扩展名替换、自动编号。先预览，再应用；改错了「撤销上次」。
面板工作台里只显示拖拽框——拖进文件后自动脱离成独立窗口。

**它不接给 agent**：清单里没有 `tools[]` 与 `skill`，agent 的工具表里
看不到它，【设置 → 插件】里也不会出现「注册到 agent」开关。
（它也不内置，不随应用分发。）

### 安装 / 更新

把 `batch-rename/` 整个目录复制到 `<userData>/plugins/` 下：

- Windows：`%APPDATA%\desk-pet\plugins\batch-rename\`
- 重启应用后，面板里搜「批量重命名」就能看到。

改了源码要重新复制一遍才生效（用户插件盖掉同名内置插件，跟内置的不是一回事）。

### 撤销记录

「撤销上次」的记录在 `<userData>/batch-rename-undo.json`（只留最近一批）。
