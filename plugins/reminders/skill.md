# 提醒

## 什么时候用

用户要设提醒、闹钟、别忘了某件事的时候用它。

这个插件管理定时提醒。到点时桌宠会播报一声。

## 工具

- `reminders.add(text)` — 加一条提醒。**时间写在正文里**，例如「30分钟后喝水」「2小时后站起来」「14:30 吃药」。
- `reminders.list()` — 列出还没触发的提醒，每条带 `id`、正文与触发时刻。
- `reminders.remove(id)` — 删掉一条提醒。

## 用法

- 用户说「30分钟后提醒我喝水」→ `reminders.add`，正文原样传过去。
- 用户问「我有哪些提醒」→ `reminders.list`。
- 用户说「把那个提醒删了」→ `reminders.list` 找到对应那条的 `id`，再 `reminders.remove`。

## 注意

- **时间解析不出来时工具会报错**：把用户的话原样再发一次，或换一种时间的写法（`30分钟后` / `2小时后` / `14:30`）。
- 只列还没触发的提醒——已经响过的不会出现在清单里。
