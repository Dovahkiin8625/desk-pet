# 待办

## 什么时候用

用户要记待办、要买菜、要列自己还有什么没做的时候用它。

这个插件管理一张待办清单。每条待办有一个 `id`，状态是「未完成」或「已完成」。

## 工具

- `todos.add(text)` — 加一条待办。
- `todos.list()` — 列出全部待办，每条带 `id`、正文与是否完成。
- `todos.toggle(id)` — 把某条在「已完成」与「未完成」之间翻一下。
- `todos.clear()` — 删掉全部已完成的待办。

## 用法

- 用户说「记一下要买菜」→ `todos.add`。
- 用户问「我还有什么没做」→ `todos.list`，只把未完成的报给用户。
- 用户说「买完了」→ 先 `todos.list` 找到对应那条的 `id`，再 `todos.toggle`。
- 用户说「清一下做完的」→ `todos.clear`。

## 注意

- **一次只处理一条**：用户说的事情如果对应多条待办，别一口气翻好几条——先把清单给用户看，确认了再动。
- 清单里没有的东西不要硬套到某条待办上。
